# Math Utility Project

A simple Java Maven project demonstrating Unit Testing with JUnit 5 and automated Continuous Integration (CI) using GitHub Actions.

### Features
- Computes factorial values for numbers from 0 to 20.
- Unit testing with comprehensive Normal, Boundary, and Abnormal test cases.
- Continuous Integration pipeline configured with GitHub Actions.
